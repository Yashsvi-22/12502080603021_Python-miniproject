StudyFlow: Smart Study Planner
A Python-based desktop application that helps students organize academic tasks, manage deadlines, and track study progress through a simple graphical interface.

About the Project
StudyFlow: Smart Study Planner is a mini project developed as part of the Programming with Python course for B.Tech. in Information Technology.

The application provides a centralized place to view subjects, manage study tasks, receive deadline alerts, and monitor completed and pending tasks. It uses a MySQL database to store task information and Matplotlib to visualize study progress.

Features

Dashboard: View academic subjects and task counts.

Add Tasks: Create new study tasks.

Edit Tasks: Update existing task details.

Delete Tasks: Remove tasks that are no longer required.

Mark as Completed: Update task completion status.

Deadline Alerts: Identify tasks that need attention.

Study Progress Chart: Visualize completed and pending tasks.

Database Integration: Store and retrieve task information using MySQL.
